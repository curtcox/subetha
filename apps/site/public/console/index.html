    devicebasedauth.org
    
        
    Devices enroll at devicebasedauth.org: you approve each one there, choose which topics it may publish and subscribe to, and can revoke it there or here. Link your devicebasedauth.org account once; its devices for subetha.us then act as this account's devices.
    
        
    Checking…
    
        
    
        
    
        
    
          Enroll a CLI, server or app
          
    dba enroll --aud subetha.us --action subetha:publish --action subetha:subscribe
dba curl -d "Backup done" https://subetha.us/@me/backups   # publish with the device credential
subetha login                                                # or: give the subetha CLI its own signing key
    
          
    Limit a device to some topics with --resource "@me/*". Browsers and apps use the devicebasedauth.org SDKs (new DBA().enroll(…), Android, iOS); see Devices.
