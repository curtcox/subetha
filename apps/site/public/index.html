Messages between any devices, over any transport.

Publish to a topic. Every subscribed device gets it over whatever works — WebSocket, push, email, Slack, SMS, voice, MCP, Reticulum, Bluetooth, audio, or QR — without knowing who else is listening or how they're reached.

ntfy-compatible

curl -H "Authorization: Bearer $SUBETHA_TOKEN" \
  -d "Backup done" https://subetha.org/@me/backups

SDKs

import { SubEtha } from "@subetha/sdk";
const se = new SubEtha({ token });
se.subscribe("@me/door", (m) => console.log(m.message));
await se.publish("@me/door", "opened");
