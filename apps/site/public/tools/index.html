Tools

Everything here runs in your browser. The first three work without an account; the rest run live against your account in the console.

Pricing calculator

Monthly cost and the top-up you need, from the same price table the relay charges from.

Route simulator

If I publish this, which transports are used, in what order, and what does it cost?

Edge lab

Send a signed message to a nearby device over sound, animated QR, or Bluetooth, with no network and at no cost.

Message composer

Publish, dry-run against a real topic, and copy the request as curl, JS, Python, Swift, Kotlin, or Dart.

Token builder

Scopes, spend caps, transports, and origins → a token and a snippet.

API explorer

Every route in the OpenAPI document, sent live with your token.

Trace viewer

Every hop, attempt, ack, and charge for a message.
