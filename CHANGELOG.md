# Changelog

All notable changes to SubEtha are tracked here.

## Unreleased (v0.1.0-dev)

### Relay & Control Plane
- **Core relay MVP**: ntfy-compatible publish/subscribe (HTTP, JSON, SSE, WebSocket, poll, `since`, filters, multi-topic, `/{topics}/auth` permission checks), `TopicDO`, `AccountDO` single-threaded prepaid ledger with credit leases and atomic alarm scheduling, D1 migrations, KV caches, R2 attachments (`X-Filename`, with canonical IDs, proper `X-Attach` precedence, and cleanup on topic deletion and frozen-account expiry), and daily cron metering/reconciliation/backups.
- **Routing & policies**: intersection of account, topic, device, token, subscription, and message policies (`allow_transports`, `deny_transports`, `min_priority`, `max_cost_usd_micros`, `deadline_s`, timezone-aware quiet hours, rate/burst limits, kill switches). Enforced on queued deliveries (with pre-delivery re-checks on retries), live (`ws`/`sse`/`poll`) connections, and `/mcp` (`deliver_mcp`); prevents capped/restricted admin tokens from minting less-restricted tokens; closes live connections on device pause/revoke or Clerk user/org deletion; deterministic `any` (cheapest-first) and `fast` (fastest-first) sorting; `mode: "all"` parallel delivery unaffected by acks.
- **Billing & fraud defenses**: Stripe Checkout top-ups, opt-in auto-recharge (with persisted failure reasons in `auto_recharge_last_error`), payment history & printable receipts, rolling 12-month volume pricing tiers, $5 new-funds telephony hold (crediting back released/unused reservations), immediate unfreeze on top-up, frozen-account lifecycle emails, global & per-account telephony circuit breakers (with SKU-scoped divergence reconciliation), Analytics Engine telemetry, multi-segment inbound SMS billing, and per-SKU usage breakdown (`/v1/usage`).
- **Transports**: live WS/SSE/poll; Web Push, FCM, APNs (with per-account BYO credentials and HTTP/2 relay); HMAC-signed webhooks + endpoint inspector; inbound/outbound email (with echo-loop guard, multipart plaintext preference, SPF/DMARC checks, and single-part HTML body extraction); Slack OAuth + bidirectional channel bindings (with fresh token lookup); Twilio SMS, MMS, WhatsApp, and Voice with DTMF ack, multi-endpoint `STOP`/`ACK` sync, and international opt-in countries priced daily; remote MCP server (`/mcp` + RFC 9728 `/.well-known/oauth-protected-resource/mcp`, `topics` OAuth scope, and device-signed requests); Reticulum/LXMF gateway (with `/ack <id>` escalation acknowledgement and startup readiness guard).

### SDKs, CLI & Edge Transports
- **Rust core (`sdk/core`)**: canonical JSON, Ed25519 signing, XChaCha20-Poly1305 E2EE, X25519 sealed-box wrapped topic keys, dedupe, store-and-forward outbox, routing planner, `TransportModule` trait, monotonic ULID generator, edge protocol codecs (audio FSK, fountain-coded QR, BLE chunking, gossip, LAN), and UniFFI bindings.
- **TypeScript SDK (`sdk/js`)**: client with dynamic `TokenProvider` (for rotating JWTs), WS→stream auto-fallback, `EdgeGossipTransport`, full typed control-plane methods, `Outbox`, `routing` planner, `TransportModule`, Shadow DOM `<subetha-feed>` and `<subetha-send>` web components (with reactive attributes and E2EE support), browser edge shims (`/edge.js`), full built subpath exports + `.d.ts` declarations, and full CLI (`pub`, `sub`, `tail`, `poll`, `cost`, `route`, `trace`, `ack`, `login`, `logout`, `whoami`, `lan`, `balance`, `prices`, `topics`, `devices`, `token`).
- **Python SDK (`sdk/python`)**: sync client (`Client` / `SubEtha`) with auto-E2EE, wrapped topic keys, `ack`/`auto_ack`, `estimate()`, signature verification, file uploads, device-signed requests, and control-plane helpers.
- **Mobile SDKs & samples**: Swift (`sdk/swift`, with pure-Swift SHA-256 fallback), Kotlin (`sdk/kotlin`, with `setTopicKey` and core outbox/deduper re-exports), Flutter (`sdk/flutter` with `setTopicKey`, `sdk/flutter_core`), React Native (`sdk/react-native` with `coreKeyWrapper`, `sdk/react-native-core`) — with `contentType`, `actions`, `publishFile`/`estimateFile`, and control-plane helpers across Swift, Kotlin, and Dart — plus Doorbell + Edge sample apps on web, CLI, Python, MCP, iOS, Android, Flutter, and React Native.

### Docs, Tools & Infrastructure
- **Web console & tools (`apps/site`)**: live console dogfooding the SDK (with dynamic Clerk token refresh, live inbox `since`/stop/clear/markdown/recent-trace picker, composer file/actions/sign snippets, subscription & device editing, auto-recharge failure banner, usage window selector, and ledger pagination), pricing calculator (tier-aware rent + inbound WhatsApp), offline route simulator (including token deny-lists), Edge lab, OpenAPI API explorer (with media-type selection and binary file uploads), copy-as snippets in 6 languages, token builder, trace viewer, endpoint inspector, per-SKU usage table, and `/status/`.
- **Spec, pricing & infra**: OpenAPI 3.1 with drift test, shared conformance vectors (`spec/vectors`), generated pricing table with CI margin invariants, Cloudflare Terraform configuration (`infra/terraform`), and GitHub Actions CI/Mobile/Pages/Deploy/Nightly/Release workflows.
